# Steam-game-analytics

<div>
    <h2> Цель проекта: </h2>
    <p> Анализировать dataset Steam games на разные значения</p>
</div>

<div>
    <h2> Что я сделал? </h2>
    <p> Анализировал датасет взятый из сайта Kaggle (url датасета находится в config) про Steam Games Dataset 2024. <br> </p>
</div>

<div><br>
  <h3> Инструменты, которые я использовал: </h3>
  <p><strong>Pandas</strong> — для работы с датасетом, и создания нового датафрейма</p>
  <p><strong>Seaborn и Matplotlib</strong> — для построения графиков</p>
  <p><strong>Модуль ast</strong> — для преобразования строку список просто в список</p>
</div>

<div><br>
    <h3> Трудности, с которыми я столкнулся: </h3>
    <p> Жанры в датасете были в формате "[]", с помощью модуля ast я перевел их в список, а после расскрыл его с помощью функции explode из pandas</p>
</div>
